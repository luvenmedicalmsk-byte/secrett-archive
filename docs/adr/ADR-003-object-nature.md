# ADR-003 — Object Nature: событийная или непрерывная природа наблюдаемого объекта

**Статус:** принято
**Основание:** ADR-002 (State Layer), Model Axes Spec, Information Gain Function/Engine Spec, Architecture Overview v1
**Область:** природа наблюдаемого объекта как аналитическое свойство; владелец — Lifecycle
**Назначение:** закрыть архитектурную брешь между Lifecycle, State Layer и Information Gain

## 1. Проблема

State Layer хранит аналитическую модель объекта и отдаёт её как Model(t−1) для сравнения с Model(t) (ADR-002). Information Gain вычисляет прирост знания как изменение модели между циклами. Но «изменение» имеет разный смысл в зависимости от **природы** объекта:

- для **дискретного события** (землетрясение, теракт, взлом) значимо само появление и его разовые характеристики; повторная публикация того же факта — не новое знание;
- для **непрерывного процесса** (тропический циклон, лесной пожар, засуха, инфляционная динамика) значимо изменение состояния во времени; объект живёт неделями, и «то же состояние» ≠ «новое состояние».

Если система не квалифицирует природу объекта, Information Gain и Lifecycle вынуждены трактовать оба класса одинаково. Это и есть брешь: непрерывный процесс, переиздаваемый источником, выглядит как поток «новых событий», а дискретное событие, повторно упомянутое, — как «продолжающийся процесс». Ни State Layer (он только хранит), ни Information Gain (он только сравнивает) не отвечают за то, *чем является объект по природе*.

## 2. Considered Alternatives

| Подход | Ограничение |
|---|---|
| Не квалифицировать природу (текущее) | Lifecycle и IG трактуют событие и процесс одинаково; переиздание процесса неотличимо от новизны; корень дефекта долгоживущих процессов |
| Природа как тип события (статично, при допуске) | тип фиксируется один раз и не отражает, что объект может наблюдаться как процесс; не переживает эволюцию наблюдения |
| Природа как свойство источника | один источник публикует и события, и процессы; атрибут источника не определяет природу объекта |
| **Природа как аналитическое свойство объекта, владелец Lifecycle** | требует, чтобы Lifecycle квалифицировал природу; зато природа становится устойчивым признаком модели, доступным IG и State Layer |

## 3. Decision

**Природа наблюдаемого объекта — событийная (дискретная) или непрерывная (процессная) — является аналитическим свойством объекта и принадлежит слою Lifecycle.** Lifecycle квалифицирует природу и удерживает её как устойчивое свойство идентичности объекта. State Layer хранит это свойство в составе модели; Information Gain интерпретирует «изменение» согласно природе: для дискретного объекта прирост знания — появление и разовые характеристики; для непрерывного — изменение состояния во времени, где переиздание того же состояния не есть новое знание.

## 4. Ответственность и границы

| Компонент | Роль относительно Object Nature |
|---|---|
| **Lifecycle** (владелец) | квалифицирует природу; связывает её со стабильной идентичностью; удерживает как устойчивое свойство между циклами |
| State Layer | хранит природу в составе Model(t); не устанавливает и не интерпретирует её |
| Information Gain | читает природу; интерпретирует «изменение модели» соответственно; не переопределяет природу |
| Domain/Severity/Geo | не владеют природой; их выводы — оси модели, но не её темпоральный класс |

## 5. Обоснование (почему владелец — Lifecycle)

Природа объекта неотделима от его идентичности и течения во времени — а это и есть предмет Lifecycle. Событие «происходит», процесс «длится»; различие между ними — темпоральное, значит принадлежит слою, отвечающему за идентичность и возраст объекта. Отдать природу State Layer нельзя (он не судит), Information Gain нельзя (он потребитель модели, а не её автор), источнику/домену нельзя (они не владеют временем жизни объекта). Единственный корректный владелец — Lifecycle.

## 6. Architectural Consequences

- Model(t) получает свойство природы объекта; State Layer хранит его наравне с прочими осями (ADR-002 §4 — состав осей уточняется этим ADR как включающий природу).
- Information Gain получает право трактовать «изменение» по-разному для событий и процессов — это устраняет ложную эквивалентность «переиздание = новизна» для непрерывных объектов.
- Lifecycle обязан квалифицировать природу как часть установления идентичности объекта.
- Появляется устойчивая граница «дискретное событие ↔ непрерывный процесс», на которую могут опираться последующие решения о жизненном цикле долгоживущих объектов.

## 7. Out of Scope

Не определяет: как именно Lifecycle квалифицирует природу (признаки/эвристики); формальные правила перехода событие↔процесс; алгоритм Information Gain для каждого класса; пороги; реализацию; roadmap.

## 8. Open Questions

Сознательно открыты: критерии квалификации природы; допустимость смены природы объекта в ходе наблюдения (событие, переросшее в процесс, и наоборот); гранулярность (могут ли быть промежуточные классы); взаимодействие природы с атомарностью объекта (составные объекты).
