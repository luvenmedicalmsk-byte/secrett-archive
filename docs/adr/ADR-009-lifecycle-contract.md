# ADR-009 — Контракт жизненного цикла долгоживущего процесса

**Статус:** Approved · **Дата:** 2026

## Контекст

Долгоживущие процессы (типа BAVI «Шторм — Тихий океан») зависали в бессрочном Critical.
Эмпирически доказано: `make_id = md5(title + date)` кладёт дату в id → ежедневное
переиздание источником (GDACS/Copernicus, NASA FIRMS, Авиалесоохрана, Росгидромет, МЧС)
получает НОВЫЙ id → движок мёрджит как новое подтверждение → last_seen = сегодня → decay
никогда не срабатывает → фаза escalating защёлкивается на evidence_total ≥ 12 → health
Critical навсегда. Дефект системный: 4 из 5 классов опасностей.

## Решение

**Источник публикует наблюдения — Process Engine интерпретирует lifecycle** (LL-9, ключевой).
Переиздание источником НЕ трактуется движком как новое развитие.

**Контракт LL-1..LL-9:**
- Новое событие = новизна по **содержанию**, не по дате.
- Re-confirmation = то же состояние (не новое, не эскалация).
- Escalation = свежая положительная content-дельта.
- Process End = маркеры (dissipated/downgraded/remnant) / конец окна / таймаут / frozen-fallback.
- `last_seen` = время последнего **изменения содержания** (переподтверждения не блокируют decay).
- `evidence_count` = независимые content-наблюдения (переиздание не считается).
- Severity half-life; Critical только на свежей content-severity + свежей дельте.
- **LL-8:** идентичность долгоживущего события — по содержанию, не только по времени публикации.
- **LL-9:** источник публикует наблюдения, движок интерпретирует lifecycle.

## Реализация (варианты)

- **B — Content-Delta Gate** (внедрён первым): классификация по net-тренду severity_history;
  плато > tempo при |net| < 5 → decay_should_start. Не трогает id/first_seen/кластеризацию →
  Continuity структурно 100%. Внедрён как Lifecycle Canary Stage 1 (climate): BAVI вышел из
  бессрочного Critical (Critical → Stable), False Decay 0, Continuity 100%.
- **C — End-markers + Severity Half-Life** (планируется вторым слоем): чтобы severity
  реально спадала со временем, а не только менялся health.
- **A — Content-Identity** (отложен): чинит корень (date-id), но несёт риск для истории.

## Следствия

- Frozen-процессы корректно затухают; переиздание не удерживает Critical.
- Реализация по ADR-005 (Shadow → Canary по доменам → Production).
