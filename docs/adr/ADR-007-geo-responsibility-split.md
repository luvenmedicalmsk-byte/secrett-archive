# ADR-007 — Разделение ответственности GEO

**Статус:** Approved · **Дата:** 2026

## Контекст

Гео-ошибки возникали в двух разных местах с разной природой, но чинились вперемешку, что
приводило к регрессиям. Нужно закрепить владельца за каждым классом гео-дефектов.

## Решение

Гео-ответственность разделяется на два независимых трека с разными владельцами; их правки
делаются **раздельно**, не в одном изменении.

- **G1 — `resolve_geo` (GeoContract).** Владелец авторитетной географии платформы: страна,
  зона, координаты, impact-страны. Единая точка истины (NO RECALCULATION ниже по потоку).
  Класс дефектов: пассивный актор принимается за место события (напр. «Белгород» как субъект
  вместо места); утечка актора в impact.

- **G3 — `signal_engine._process_place`.** Владелец гео на уровне процесса (агрегация).
  Класс дефектов: утрата контрактного `place=None` в дипломатических/безместных процессах
  (кейсы, где событие валидно без физического места).

**Принцип:** G1 и G3 — разные владельцы, разные задачи. Смешивание правок возвращает
регрессии. Каждый трек реализуется отдельной audited-задачей.

## Следствия

- Гео вычисляется контрактом один раз (G1); процессный слой (G3) его не пересчитывает.
- Безместные сигналы (кибер/эконом/санкции/дипломатия) — валидны с `place=None`, не дефект.
