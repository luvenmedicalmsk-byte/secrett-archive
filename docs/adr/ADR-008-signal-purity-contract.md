# ADR-008 — Контракт чистоты сигнала (Signal Purity Contract)

**Статус:** Approved · **Дата:** 2026

## Контекст

«Сигнал» и «новость» смешивались. Заявления, мнения, обзоры, развлекательный шум попадали
в аналитический контур наравне с реальными событиями, искажая процессы и pressure.

## Решение

**Сигнал = N1 ∧ N2 ∧ N3** (все три обязательны, проверяются по финальному русскому тексту,
после перевода/нормализации — иначе воспроизводится языковой дефект допуска):

- **N1 — событийность.** Реальное действие / инцидент / изменение, а не речь о нём. Заявления,
  мнения, эссе, обзоры, прогнозы — не N1. (Исключение: реальные РЕШЕНИЯ — санкции, закон,
  закрытие границы, мобилизация — это события, не риторика.)
- **N2 — риск-релевантность.** Изменение наблюдаемого процесса в домене (доменный словарь
  риск-сигнатур). Событие без риск-релевантности к своему домену — новость, не сигнал.
- **N3 — фактичность.** Подтверждённый факт, а не намерение/угроза/прогноз. Уровни
  подтверждённости (expectation/statement/negotiation/preliminary) понижают severity и
  помечают карточку.

**Инварианты SP-1..SP-9** — набор проверок согласованности (напр. военная атака/жертвы не
остаются в economy; церемония не несёт высокой severity; профилактическое предупреждение не
весит как инцидент; origin согласован с доменом).

**Admission — отдельный слой** (не Canonizer, ADR-006). Диагностический контур публикует
FP-кандидатов, но Purity как KPI не публикуется до Shadow Stable (классификатор в калибровке).

## Следствия

- Слабый сигнал (ниже порога ленты) допускается в аналитику только при аналитической
  ценности (риск-сигнатура / страна+домен), иначе остаётся вне ленты и вне аналитики.
- Классификация по финальному тексту (SP-7) — обязательна, чтобы не отсекать по языку
  источника.
